## Core Features & AI (핵심 기능 및 AI 활용) 전략

1인 개발 범위 내에서 실행 가능한 차별화 기능들입니다. (AR/지오펜스/온디바이스 임베딩 모델/자체 NLP 등 솔로 범위를 넘는 항목은 2026-05-20 기준으로 스코프에서 제외했습니다.)

- [x] **[Feature] 로컬 텍스트 인식(OCR) 통합**: 이미지 라벨링 뿐만 아니라 사진 속의 텍스트(영수증, 명함, 간판 등)를 로컬에서 인식해 검색 가능하도록 추가. (v1.6.0)
- [ ] **[AI] 스마트 앨범/자동 폴더링**: 태그의 유사도나 촬영 날짜, 시간대를 기반으로 '이번 주 데스크 정리', '작업실' 등 자동으로 컬렉션을 묶어주는 기능.
- [ ] **[Feature] 홈 위젯(Widget) 지원**: 바탕화면에서 바로 카메라를 켜서 기록하거나, 최근 기록한 시각적 메모를 보여주는 위젯 제공.
- [ ] **[AI] Gemini Vision 프롬프트 템플릿 제공**: "이 사진에서 레시피 추출해줘", "이 영수증의 총액과 날짜 정리해줘" 등 자주 쓰는 고급 분석 프롬프트를 템플릿화.
- [ ] **[Feature] 사진 내 특정 영역 확대/크롭 기록**: 큰 사진 전체가 아니라 특정 물건만 잘라내어 별도의 서브 메모로 저장하는 기능.
- [ ] **[Feature] 오디오 메모 첨부 기능**: 사진을 찍을 때 손이 바쁜 상황을 고려해, 음성으로 짧게 녹음하고 메모에 자동 첨부.
