## Core Features & AI (핵심 기능 및 AI 활용) 전략

플레이 스토어 Top 10 진입을 위해 경쟁력을 갖춘 차별화 기능 10가지 전략입니다.

- [x] **[Feature] 로컬 텍스트 인식(OCR) 통합**: 이미지 라벨링 뿐만 아니라 사진 속의 텍스트(영수증, 명함, 간판 등)를 로컬에서 인식해 검색 가능하도록 추가. (v1.6.0)
- [ ] **[AI] 스마트 앨범/자동 폴더링**: 태그의 유사도나 촬영 날짜, 시간대를 기반으로 '이번 주 데스크 정리', '작업실' 등 자동으로 컬렉션을 묶어주는 기능.
- [ ] **[Feature] 홈 위젯(Widget) 지원**: 바탕화면에서 바로 카메라를 켜서 기록하거나, 최근 기록한 시각적 메모를 보여주는 위젯 제공.
- [ ] **[AI] Gemini Vision 프롬프트 템플릿 제공**: "이 사진에서 레시피 추출해줘", "이 영수증의 총액과 날짜 정리해줘" 등 자주 쓰는 고급 분석 프롬프트를 템플릿화.
- [ ] **[Feature] 사진 내 특정 영역 확대/크롭 기록**: 큰 사진 전체가 아니라 특정 물건만 잘라내어 별도의 서브 메모로 저장하는 기능.
- [ ] **[Feature] 위치 기반 메모 트리거**: 특정 장소(예: 창고, 사무실)에 도착했을 때 해당 위치에서 기록했던 사진과 메모를 푸시 알림으로 리마인드. (옵션 권한)
- [ ] **[AI] 오프라인 유사 이미지 검색**: 텍스트 검색뿐만 아니라, 비슷한 색감이나 형태를 가진 사진들을 로컬 환경에서 클러스터링하여 찾아주는 기능.
- [ ] **[Feature] 오디오 메모 첨부 기능**: 사진을 찍을 때 손이 바쁜 상황을 고려해, 음성으로 짧게 녹음하고 이를 STT(로컬)로 변환해 메모에 자동 기입.
- [ ] **[Feature] AR 거리/크기 측정 기록 지원**: ARCore를 활용해 사진을 찍을 때 상자의 크기나 가구의 길이를 함께 기록해 시각적 메모의 활용도를 극대화.
- [ ] **[AI] 자연어 기반 복합 검색**: "지난 주에 찍은 파란색 상자", "노트북 옆에 있던 컵" 등 문장 형태의 검색어를 해석하여 매칭되는 사진 검색.
