## Security, Privacy & Trust (보안, 프라이버시 및 신뢰) 전략

플레이 스토어 Top 10 진입을 위해 사용자의 민감한 데이터를 보호하고 신뢰를 구축하는 10가지 전략입니다.

- [ ] **[Sec] 생체 인증(Biometrics) 잠금 기능**: 민감한 시각적 메모 보호를 위해 앱 실행 시 지문/얼굴 인식을 요구하는 프라이버시 잠금 옵션 제공.
- [ ] **[Sec] 갤러리 숨김(No Media) 모드**: MarkScene에서 찍은 사진이 시스템 기본 갤러리나 다른 앱에 노출되지 않도록 철저히 격리하는 기능.
- [ ] **[Sec] API Key 암호화 스토리지 강화**: Android Keystore 기반으로 BYOK 키를 암호화하고, 앱 삭제 시 잔여 데이터가 완벽히 소거되도록 설정.
- [ ] **[Privacy] 권한 요청 시나리오 투명화**: 카메라나 사진 접근 권한을 요구할 때, 시스템 팝업 전에 "왜 이 권한이 필요한지" 친절하게 설명하는 사전 안내창 도입.
- [ ] **[Trust] 로컬 처리 인증 배지 UI**: 현재 태깅이 네트워크 없이 로컬 기기에서 100% 안전하게 처리되고 있음을 나타내는 '방패 모양' 아이콘이나 상태 표시줄 추가.
- [ ] **[Privacy] EXIF 메타데이터 제거 옵션**: 기록된 사진을 외부(다른 앱)로 내보낼 때 위치 정보 등 민감한 EXIF 데이터를 자동으로 지워주는 옵션.
- [ ] **[Trust] 투명한 데이터 내보내기/가져오기 (JSON/ZIP)**: 벤더 락인(Vendor Lock-in) 없이 언제든 사용자가 자신의 모든 기록과 태그를 표준 포맷으로 백업하고 다른 기기로 옮길 수 있는 기능.
- [ ] **[Sec] 클립보드 보호**: API Key를 복사/붙여넣기 할 때 다른 앱이 클립보드를 스누핑하지 못하도록 Android 13+ 권장 보안 가이드라인 준수.
- [ ] **[Trust] 프라이버시 영수증(Privacy Dashboard)**: 지난 7일 동안 앱이 언제 어떤 권한(카메라, 로컬 ML)을 사용했는지 한눈에 보여주는 투명성 대시보드 추가.
- [ ] **[Sec] 스크린샷 방지 옵션**: 사용자가 극도로 민감한 정보를 다룰 때 앱 내 화면 캡처 및 화면 녹화를 시스템 레벨(FLAG_SECURE)에서 차단하는 토글 제공.
