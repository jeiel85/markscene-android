MarkScene • Android • Local First

사진을 검색 가능한 비주얼 메모로

MarkScene은 사진을 로컬 태그와 메모로 구조화해 나중에 빠르게 찾을 수 있게 만드는 프라이버시 우선 Android 앱입니다.

Local First

기본 기능은 API Key 없이 기기에서 바로 동작하며, 로컬 저장/검색을 우선합니다.

Editable AI

태그와 분석 결과는 확정값이 아니라 제안으로 제공되며, 사용자가 직접 수정합니다.

BYOK Advanced

고급 분석은 사용자가 실행할 때만 수행되며, BYOK 설정에서 선택적으로 사용합니다.
