사진을 검색 가능한
비주얼 메모로

MarkScene은 사진 기록을 로컬 태그와 메모로 구조화해, 다시 찾는 시간을 줄여주는 프라이버시 우선 Android 앱입니다.

📦 APK 다운로드 🔧 GitHub 저장소 🎨 브랜딩 페이지

기본 기능은 API Key 없이 동작하며, 고급 분석은 BYOK(Bring Your Own Key) 기반 선택 기능입니다.

주요 기능

📸
사진 촬영 & 가져오기
Android Photo Picker로 안전하게 사진을 선택하거나, CameraX 기반의 카메라로 즉시 촬영하세요.
🏷
자동 태그 생성
ML Kit 온디바이스 라벨링으로 사진 속 주요 객체를 자동으로 태그 초안으로 생성합니다.
✏️
태그 편집 & 메모
생성된 태그를 수정, 삭제, 추가하고 사진에 대한 메모를 자유롭게 작성하세요.
🔍
빠른 검색
태그, 제목, 메모를 기반으로 저장된 사진 기록을 즉시 검색할 수 있습니다.
🤖
BYOK 고급 AI 분석
본인의 API Key를 입력해 Gemini 기반 고급 이미지 분석을 선택적으로 사용하세요.
🔒
프라이버시 보호
모든 데이터는 기기 내부에 저장되며, API Key는 Android Keystore로 암호화 보관됩니다.

프라이버시 우선 설계

🔐 MarkScene는 언제든지 당신의 데이터를 존중합니다

  • 기본 플로우에서 사진을 외부 서버로 업로드하지 않음
  • Android Photo Picker 사용으로 전체 갤러리 접근 차단
  • MANAGE_EXTERNAL_STORAGE 권한 사용 안 함
  • API Key는 기기 내부에만 암호화 저장
  • 로그에 API Key, 사진 바이트, 개인정보 기록 안 함
  • BYOK 방식으로 사용자가 직접 API Key 관리
  • AI 분석은 사용자가 명시적으로 실행한 경우만
  • 외부 전송 시 사전 고지 및 동의 절차
