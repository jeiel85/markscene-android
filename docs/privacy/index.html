MarkScene 홈으로

개인정보 처리방침

최종 업데이트: 2026-05-26

요약

MarkScene은 사진을 검색 가능한 비주얼 메모로 저장하는 로컬 우선 Android 앱입니다. 기본 기능은 개발자 서버나 API Key 없이 동작하며, 사진, 태그, 메모는 기본적으로 사용자의 기기 안에서 처리하고 저장합니다.

기기에 저장되는 정보

  • 사용자가 촬영하거나 선택한 사진의 앱 내부 참조 또는 앱 관리 저장소 사본
  • 사용자가 작성한 제목, 메모, 태그, 기억 유형, 다시 보기 상태
  • 로컬 태그 및 OCR 결과, 고급 분석을 사용한 경우의 분석 메타데이터
  • 선택 기능인 BYOK AI 분석을 위해 사용자가 저장한 API Key

외부 전송

기본 기록, 태그 생성, OCR, 검색 플로우에서는 사진이나 메모를 외부 서버로 전송하지 않습니다. 사용자가 고급 AI 분석을 명시적으로 실행한 경우에만 선택한 이미지와 분석에 필요한 프롬프트가 사용자가 선택한 AI 제공자에게 전송될 수 있습니다.

API Key 보호

API Key는 선택 기능이며 앱 사용을 위해 필수로 요구하지 않습니다. 저장된 API Key는 Android Keystore 기반 암호화 저장소에 보관하며, 개발자 서버로 전송하지 않고 로그에도 남기지 않습니다.

권한

  • 카메라 권한은 사용자가 사진 촬영 기능을 사용할 때 필요합니다.
  • 인터넷 권한은 사용자가 BYOK 고급 AI 분석을 실행할 때 필요합니다.
  • MarkScene은 MANAGE_EXTERNAL_STORAGE, 광범위한 사진/동영상 권한, 백그라운드 위치 권한을 사용하지 않습니다.

삭제와 제어

사용자는 저장된 기록을 삭제할 수 있으며, API Key도 설정에서 삭제할 수 있습니다. EXIF 제거, 갤러리 숨김, 앱 전체 스크린샷 차단 같은 보안 옵션은 사용자가 직접 제어합니다.

더 자세한 문서

저장소의 PRIVACY_POLICY.md와 PRIVACY_AND_SECURITY.md에서 프로젝트 기준 문서를 함께 확인할 수 있습니다.
