# MarkScene 개인정보 처리방침 (초안)

> **⚠️ 이 문서는 초안이며, 실제 배포 전 법률 검토가 필요합니다.**

## 1. 개요

MarkScene(이하 "앱")은 사용자의 사진을 검색 가능한 비주얼 메모로 변환하는 Android 애플리케이션입니다.  
본 앱은 **로컬 우선(Local-First)** 설계 원칙에 따라, 기본적으로 사용자 데이터를 외부로 전송하지 않습니다.

## 2. 수집하는 정보

### 2.1 기기에 저장되는 정보 (로컬 저장)

| 항목 | 설명 | 저장 위치 |
|------|------|----------|
| 사진 참조 | 선택/촬영한 사진의 참조 경로 또는 앱 내부 복사본 | 기기 내부 저장소 |
| 제목 | 사용자가 입력한 사진 제목 | Room 데이터베이스 |
| 메모 | 사용자가 작성한 메모 | Room 데이터베이스 |
| 태그 | 로컬/AI 생성 태그 (사용자 수정 가능) | Room 데이터베이스 |
| 분석 메타데이터 | 고급 AI 분석 결과 요약 | Room 데이터베이스 |
| API Key (선택) | BYOK 방식의 API Key (암호화 저장) | EncryptedSharedPreferences |

### 2.2 외부로 전송되는 정보

**기본 플로우에서는 외부 전송이 발생하지 않습니다.**

다음 상황에서만 데이터가 외부로 전송됩니다:
- 사용자가 **직접** "고급 AI 분석 실행" 버튼을 누른 경우
- 이 경우: 선택한 사진(리사이즈 복사본), 분석용 프롬프트, API Key가 선택한 AI 제공자에게 전송됨

## 3. 정보의 이용 목적

- 사진 기록의 로컬 저장 및 관리
- ML Kit 기반 온디바이스 태그 자동 생성
- 사용자 요청 시 BYOK AI 제공자(예: Gemini)를 통한 고급 이미지 분석
- 태그/제목/메모 기반 로컬 검색

## 4. 정보의 보관 및 삭제

### 4.1 보관
- 모든 데이터는 사용자의 **기기 내부**에만 저장됩니다.
- 앱을 삭제하면 기기 내부 데이터베이스도 함께 삭제됩니다.

### 4.2 삭제 권리
사용자는 언제든지:
- 개별 사진 기록 삭제 (기록 목록/상세 화면)
- API Key 삭제 (설정 화면)
- 전체 앱 삭제를 통한 모든 데이터 삭제

를 수행할 수 있습니다.

## 5. 외부 서비스 연동

### 5.1 BYOK AI 제공자 (선택 기능)
- 사용자가 자신의 API Key를 입력한 경우에만 연동됩니다.
- 지원 제공자: Google Gemini (추가 예정)
- 전송 데이터: 선택한 사진, 분석 프롬프트, API Key
- 제공자의 개인정보처리방침이 별도로 적용됩니다.

## 6. 권한 사용

| 권한 | 목적 | 필수 여부 |
|------|------|----------|
| 카메라 | 사진 촬영 | 선택 (Photo Picker만으로도 앱 사용 가능) |
| 인터넷 | BYOK AI 분석 시 통신 | 선택 (로컬 기능은 오프라인 동작) |

MarkScene는 다음 권한을 **사용하지 않습니다**:
- MANAGE_EXTERNAL_STORAGE (전체 저장소 관리)
- READ_MEDIA_IMAGES / READ_EXTERNAL_STORAGE (광범위 갤러리 접근)
- ACCESS_BACKGROUND_LOCATION (백그라운드 위치)

## 7. 보안 조치

- API Key는 **Android Keystore 기반 암호화 저장소**(EncryptedSharedPreferences)에 보관
- 로그에 API Key, 사진 바이트, 개인정보 기록 안 함
- 개발자 소유 서버로의 데이터 전송 없음
- Photo Picker 사용으로 갤러리 접근 최소화

## 8. 어린이의 개인정보

MarkScene는 13세 미만 어린이를 대상으로 하지 않으며, 고의로 어린이의 개인정보를 수집하지 않습니다.

## 9. 정책 변경
