# Product Brief

## Product Name

Final working name: MarkScene.

Default repository name: markscene-android.
Default Android applicationId: `com.markscene.app`.

## One-Line Description

A privacy-first Android app that turns photos into searchable visual notes with fast local tags and optional advanced AI analysis.

## Problem

People often take photos to remember where things are, what was in a box, what was on a desk, or what a place looked like. Standard galleries store the image but do not turn the contents into editable, searchable personal records.

## Target Users

Initial target users:

- People who want to remember where items are.
- People who organize desks, shelves, boxes, rooms, or storage spaces.
- Users comfortable downloading an optional local AI model for deeper analysis.
- Privacy-conscious users who prefer local-first apps.

Not the initial target:

- Users who expect a fully managed cloud AI product.
- Users who want social sharing.
- Users who want automatic whole-gallery indexing.

## Core Value

MarkScene should reduce the effort required to create a useful record from a photo.

Instead of manually writing:

> Desk with laptop, keyboard, mouse, mug, and charger.

The user should be able to take a photo and get editable tag chips such as:

> laptop, keyboard, mouse, mug, charger, desk

## Product Positioning

MarkScene is not trying to beat general image search products. It is a personal memory and organization tool.

The app should be useful even when offline and without an external AI API key.

## Key Differentiator

Photos become structured, editable, searchable records.
