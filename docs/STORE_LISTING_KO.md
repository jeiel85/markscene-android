# MarkScene Play Store Listing (KO)

## 앱 이름 제안
- MarkScene - 사진 비주얼 메모

## 짧은 설명 (80자)
- 사진을 검색 가능한 비주얼 메모로 저장하고, 태그로 빠르게 다시 찾으세요.

## 긴 설명 (핵심 ASO 키워드 포함)
MarkScene은 사진을 기록으로 바꾸는 로컬 우선 비주얼 메모 앱입니다.

- 사진 촬영/가져오기 후 자동 태그 초안 생성
- 태그/제목/메모 기반 빠른 검색
- 공간별 분류와 타임라인 정리
- API Key 없이 기본 기능 사용 가능
- 고급 AI 분석은 BYOK 옵션으로 선택 실행

주요 키워드: 사진 정리, 사진 메모, 태그 검색, 비주얼 메모, 로컬 저장, 사진 기록, 물건 찾기, 공간 정리

개인정보/보안:
- 기본 플로우는 로컬 처리 중심
- 사용자가 선택한 경우에만 외부 AI 전송
- API Key는 기기 내부 보안 저장소에 암호화 보관
