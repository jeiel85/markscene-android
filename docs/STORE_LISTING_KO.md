# MarkScene Play Store Listing (KO)

문서 기준: v2.6.1

## 앱 이름 제안
- MarkScene - 사진 비주얼 메모

## 짧은 설명 (80자)
- 사진 속 장면을 태그, 메모, Recall Box로 다시 찾는 개인 비주얼 메모

## 긴 설명 (핵심 ASO 키워드 포함)
MarkScene은 사진을 기록으로 바꾸는 로컬 우선 비주얼 메모 앱입니다.

- 사진 촬영/가져오기 후 로컬 태그와 OCR 초안 생성
- 태그/제목/메모/OCR 텍스트/기억 유형 기반 빠른 검색
- Scene Timeline과 Recall Box로 다시 볼 장면 정리
- EXIF 제거, 갤러리 숨김, 자동 잠금, 스크린샷 차단 옵션
- 공유 템플릿, 이미지 크롭, Markdown/CSV 내보내기
- API Key 없이 기본 기능 사용 가능
- 로컬 VLM 모델을 다운로드하면 API Key 없이 고급 AI 분석 가능
- 외부 고급 AI 분석은 BYOK 옵션으로 선택 실행

주요 키워드: 사진 정리, 사진 메모, 태그 검색, 비주얼 메모, 로컬 저장, 사진 기록, 물건 찾기, 공간 정리

개인정보/보안:
- 기본 플로우는 로컬 처리 중심
- 로컬 VLM 분석은 외부 서버 전송 없이 기기 안에서 처리
- 사용자가 외부 AI를 선택한 경우에만 이미지 전송
- API Key는 외부 AI 분석용 선택 값이며 기기 내부 보안 저장소에 암호화 보관
