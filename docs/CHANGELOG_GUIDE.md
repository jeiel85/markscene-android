# Changelog Guide

Use a simple human-readable changelog.

## Categories

- Added
- Changed
- Fixed
- Removed
- Security
- Privacy

## Rules

- Write for users, not only developers.
- Mention privacy-impacting changes clearly.
- Mention permission changes clearly.
- Do not include internal secrets or sensitive implementation details.
- Keep entries concise.

## Example

```md
## 0.1.0

### Added

- Added photo selection using Android Photo Picker.
- Added editable tag chips for visual records.
- Added local record search by tags.

### Privacy

- Added a warning before optional external AI analysis.
- Added local API key deletion in settings.
```
